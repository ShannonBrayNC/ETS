# EXP-001 Packet Generation Contract

For each frozen scenario, generate three evaluator-facing representations with opaque format labels. Each packet must preserve the same reconstruction-material facts, contradictions, uncertainties, authority state, timestamps, command/execution/result stages, and source dependencies. Only representational semantics may differ. Each packet must include the fixed six reconstruction questions and must not expose hypotheses, trap categories, scoring keys, or condition identity.

EXP-001 remains NOT EXECUTED until all packets are frozen, independently reviewed for fact equivalence, hashed, assigned, and institutionally cleared for human evaluator recruitment where required.
