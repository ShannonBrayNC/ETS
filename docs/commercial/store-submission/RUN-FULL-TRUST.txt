ETS Desktop Developer uses runFullTrust to run its packaged Windows desktop host and bundled verifier process under the signed-in user's existing permissions. It reads files the user selects and writes synthetic examples, verification reports, and an SDK archive to destinations the user chooses. The built-in workflow does not require elevation, install services or drivers, modify machine trust, or execute imported evidence as code. The capability supports the packaged Win32/Python host, native file dialogs, and its fixed verifier subprocess. It does not request administrator privileges or claim AppContainer isolation.
