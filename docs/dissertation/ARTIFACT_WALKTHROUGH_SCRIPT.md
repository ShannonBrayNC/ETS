# Sprint 8 Artifact Walkthrough Script

## Purpose

This script prepares a short advisor-facing walkthrough of the ETS repository.
It is designed for a 10-15 minute meeting segment, not a live defense demo.

## Walkthrough Order

### 1. Start With The Advisor Packet

Open:

```text
docs/dissertation/MST_ADVISOR_REVIEW_PACKET.md
```

Say:

> This packet summarizes the return-to-PhD ask and points to the current
> dissertation artifacts.

### 2. Show Claim Discipline

Open:

```text
docs/dissertation/CLAIM_AUDIT.md
```

Point out:

- implemented claims;
- bounded models;
- pending work;
- explicit non-claims.

### 3. Show Literature Positioning

Open:

```text
docs/dissertation/RELATED_WORK_MATRIX.md
docs/dissertation/BIBLIOGRAPHY.md
```

Say:

> ETS is positioned as synthesis across transparency logs, distributed systems,
> formal methods, provenance, AI governance, and reproducibility.

### 4. Show Formal Proof Status

Open:

```text
docs/dissertation/PROOF_STATUS_TABLE.md
docs/dissertation/MODEL_CHECKING_COMMAND_LOG.md
```

Say:

> The formal layer is bounded and categorized. TLC, Apalache, Lean,
> refinement, and theorem proof are not collapsed into one claim.

### 5. Show Reproducibility

Open:

```text
docs/dissertation/IMPLEMENTATION_REPRODUCIBILITY_AUDIT.md
docs/dissertation/EXPERIMENT_ARTIFACT_PLAN.md
```

Mention:

- golden vectors;
- replay manifest;
- JSON/Markdown outputs;
- bounded experiment interpretation.

### 6. Show Assembly Plan

Open:

```text
docs/dissertation/DISSERTATION_ASSEMBLY_PLAN.md
docs/dissertation/COMMITTEE_DRAFT_READINESS.md
```

Say:

> This is ready for advisor review, not committee circulation. The next step is
> advisor approval of thesis framing, chapter sequence, and required evidence.

### 7. Close With The Ask

Ask:

1. Is ETS viable as the dissertation topic?
2. Which chapter should I turn into full prose first?
3. Which evidence package is required before committee review?
4. What administrative steps are required to resume the PhD path?
