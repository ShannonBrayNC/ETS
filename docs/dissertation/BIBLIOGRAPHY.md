# ETS Dissertation Bibliography

## Purpose

This Sprint 3 bibliography is a working source list for advisor review and
future dissertation editing. It is not yet a final university-formatted
bibliography. Entries are grouped by research area so the advisor can quickly
see where ETS is grounded and where Sprint 3 still needs deeper reading.
