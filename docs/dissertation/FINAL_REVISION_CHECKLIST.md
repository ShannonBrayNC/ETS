# Sprint 8 Final Revision Checklist

## Purpose

This checklist defines what must happen after advisor feedback and before any
committee-facing dissertation draft or defense package is circulated.

## Advisor Feedback Gate

- [ ] Advisor confirms whether ETS is viable as dissertation topic.
- [ ] Advisor confirms department/committee path.
- [ ] Advisor identifies required publication or paper expectations.
- [ ] Advisor approves or revises thesis statement.
- [ ] Advisor chooses first chapter/paper priority.

## Dissertation Draft Gate

- [ ] Chapter 1 integrated into continuous prose.
- [ ] Chapter 2 citations normalized.
- [ ] Chapter 3 definitions tightened.
- [ ] Chapter 4 figures created.
- [ ] Chapter 5 formal outputs captured.
- [ ] Chapter 6 implementation paths explained.
- [ ] Chapter 7 experiment artifact package generated.
- [ ] Chapter 8 governance scope approved.
- [ ] Chapter 9 limitations consolidated.
- [ ] Chapter 10 conclusion revised after chapter edits.

## Evidence Gate

- [ ] TLC workflow run URL captured.
- [ ] Apalache workflow run URL captured if required.
- [ ] Lean workflow run URL captured.
- [ ] Test summary captured.
- [ ] Golden-vector summary captured.
- [ ] Experiment output bundle generated.
- [ ] Benchmark timing caveat included.

## Formatting Gate

- [ ] Missouri S&T dissertation formatting checked.
- [ ] Figures and tables numbered.
- [ ] References formatted consistently.
- [ ] Appendix order confirmed.
- [ ] DOCX/PDF render reviewed.

## Defense Gate

- [ ] Defense deck drafted.
- [ ] `DEFENSE_QA.md` updated after advisor feedback.
- [ ] Artifact walkthrough rehearsed.
- [ ] Non-claims are visible in slides.
- [ ] Demo failure fallback is documented.
