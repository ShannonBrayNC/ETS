# Chapter Integration Checklist

## Purpose

This checklist tracks what each dissertation chapter must contain before the
draft can be circulated to a committee.

## Chapter 1: Introduction

- [ ] Verification gap is stated in one paragraph.
- [ ] Thesis statement uses bounded ETS language.
- [ ] Research questions are numbered and aligned to contributions.
- [ ] Contributions are mapped to chapters.
- [ ] Non-claims are visible before the roadmap.

## Chapter 2: Literature Review

- [ ] Certificate Transparency, Trillian, Sigsum, and Merkle lineage are cited.
- [ ] PBFT and FLP boundaries are explained.
- [ ] TLA+, Alloy, Apalache, and Lean are positioned accurately.
- [ ] W3C PROV, in-toto, SLSA, NIST AI RMF, Model Cards, and datasheets are included.
- [ ] Related-work matrix is converted into prose.
- [ ] Citation style is normalized.

## Chapter 3: Evidence Theory

- [ ] Evidence, observation, proof, confidence, trust, and suspicion are defined.
- [ ] Evidence/truth distinction is explicit.
- [ ] Omission suspicion requires an expectation model.
- [ ] Replay visibility and epistemic degradation are explained.
- [ ] Examples are included without product framing.

## Chapter 4: Protocol Architecture

- [ ] Evidence-event lifecycle figure is included.
- [ ] Canonicalization and hash semantics are described.
- [ ] Append-only log and proof-bundle flow are described.
- [ ] Verifier federation is introduced without consensus overclaiming.
- [ ] Privacy/redaction boundary is stated.

## Chapter 5: Formal Models and Verification

- [ ] TLA+ model families are listed.
- [ ] TLC, Apalache, and Lean validation categories are separated.
- [ ] Proof-status table is incorporated.
- [ ] Model-checking command log is summarized.
- [ ] Local-tool limitations and CI evidence are distinguished.
- [ ] Refinement proof remains pending unless completed.

## Chapter 6: Reference Implementation

- [ ] Python package architecture is summarized.
- [ ] Canonicalization, logs, proofs, federation, experiments, and artifacts are mapped.
- [ ] Golden vector coverage is included.
- [ ] Implementation is framed as research platform, not production-certified system.

## Chapter 7: Evaluation and Reproducibility

- [ ] Test vectors are summarized.
- [ ] Benchmark JSON/Markdown output is described.
- [ ] Replay manifest scenarios are listed.
- [ ] Fork, omission, federation, async, liveness, and probabilistic tests are summarized.
- [ ] Machine-dependent timing caveat is included.
- [ ] Artifact package layout is included.

## Chapter 8: Governance and AI Accountability

- [ ] AI governance evidence examples are bounded.
- [ ] NIST AI RMF and Model Cards relationship is described.
- [ ] Governance escalation is process classification, not legal authority.
- [ ] Legal sufficiency is explicitly not claimed.

## Chapter 9: Limitations and Future Work

- [ ] Non-claims are consolidated.
- [ ] Future work maps to proof, vectors, experiments, and case studies.
- [ ] No new unsubstantiated claims are introduced.

## Chapter 10: Conclusion

- [ ] Thesis is restated.
- [ ] Contributions are summarized.
- [ ] Bounded-defensibility framing closes the dissertation.
