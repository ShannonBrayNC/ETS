## Important epistemic correction

Some older manuscript passages use `truth` too strongly, including formulations that can be read as though adding verifiable evidence converts an assertion into objective truth. That language is superseded.

The current architecture distinguishes:

- provenance;
- integrity;
- authentication;
- authorization / standing;
- epistemic warrant;
- consequence evidence;
- objective reality.

No one of these automatically implies the others.

Use the September 11 synchronization addendum and the canonical dissertation/research sources when preparing the next integrated technical-manual edition.
