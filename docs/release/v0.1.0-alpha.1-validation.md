# ETS v0.1.0-alpha.1 Validation Record

Status: pre-tag release validation record.

This release advances the public alpha identity without rewriting the historical
`v0.1.0-alpha` tag created on July 21, 2026. The historical tag remains an
immutable repository artifact and is not a publication source for the SDK-4
package set.

## Release identity

- GitHub release tag: `v0.1.0-alpha.1`
- Application SDK contract: `ets.application.sdk.v1`
- Python distribution: `lanternprotocol-ets==0.1.0a1`
- NuGet package: `LanternProtocol.ETS.Application@0.1.0-alpha.1`
- npm package: `@lanternprotocol/ets-sdk@0.1.0-alpha.1`
- Target branch: `main`

The machine-readable authority is `docs/sdk/RELEASE_MATRIX.json`.

## Provenance rule

The public publish workflow fails unless:

1. the GitHub release tag matches `RELEASE_MATRIX.json`;
2. the checked-out tag resolves to exactly the current `origin/main` commit;
3. release-matrix/package metadata validation succeeds;
4. all package builds and cross-language tests succeed.

Historical release tags must never be moved or overwritten to satisfy a newer
release.

## Registry prerequisites

Before publishing the GitHub release, independently confirm:

- the `sdk-public-release` GitHub environment exists and has the intended
  reviewer protection;
- the PyPI trusted publisher is configured for `lanternprotocol-ets`;
- the `@lanternprotocol` npm scope and trusted publisher are controlled by the
  release owner;
- NuGet.org trusted publishing is configured for
  `LanternProtocol.ETS.Application`;
- repository variable `NUGET_USER` matches the NuGet.org trusted-publisher
  identity.

The repository intentionally stores no long-lived registry publishing token.
