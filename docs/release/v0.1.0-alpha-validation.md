## Known release limitations

- ETS v0.1.0-alpha is for protocol review, controlled pilots, and local or explicitly configured validation environments.
- ETS stores metadata and hashes, not raw evidence bytes.
- Local unsigned tree heads are not production trust anchors.
- Local header and API-key authentication modes are development or demonstration profiles only.
- Hosted deployments should use the production JWT/JWKS profile.
- SQLite is acceptable for local validation and controlled pilots, not final horizontally scaled hosted storage.
- Production key discovery, automated rotation, multi-tenant operations, and hosted storage hardening remain future work.

## Release decision

Do not tag `v0.1.0-alpha` until:

- PR #154 receives independent approval and merges to `main`;
- PR #156 is retargeted to `main` after PR #154 merges;
- required CI is visible and passing on the final merged commit;
- release notes and the alpha checklist match the tested commit.
